# Phase 8 — Color-coded selection phases

- Adds Start / Middle / End selection-phase chooser and custom named phases.
- Each phase has its own mask, restored when switching phases.
- Change highlight color with the native color dialog; default green, blue, purple.
- Highlights are UI-only; never applied to committed artwork or exports.
- Slime Buddy explains the feature when enabled.
- Phase switching clears temporary Slimer undo history to prevent applying a snapshot to the wrong phase.
- This is source only: Windows portable and installer binaries require a Windows build.
