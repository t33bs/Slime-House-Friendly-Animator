# Phase 1 — Slimer highlight brush hotkeys

Added + and = to increase Slimer highlight brush size, and - to decrease it. Shortcuts operate only when Slimer is active, clamp to the existing 1–32 pixel size range, and show the selected size in the status line. The brush size control now displays (+ / -) and explains the shortcuts in its tooltip.

Automated suite: 214 passed, 433 subtests passed. Actual keyboard handling on Windows (including numpad and focused widgets) still needs GUI verification.
