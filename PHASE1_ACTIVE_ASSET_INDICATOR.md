# Phase 1: active asset indicator

The Asset Library's editable sizing and placement controls now show a dynamic **Editing: [asset name]** label rather than a generic heading. Selecting a library row updates the label; clearing selection displays **Editing: No asset selected**. Slimer pose labels are refreshed after timeline changes, and the active label follows those changes.

This does not change asset storage, layer identities, or pixel data. Windows GUI validation remains outstanding. Import Pose PNG and Save As changes from the consolidated baseline are retained.
